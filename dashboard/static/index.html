      About

      What it does

      Point it at a project folder. It reads the project, runs only the checks that apply (Python version, libraries, imports, API keys, local services, GPU), and gives one prioritized report with a health score.

      It also works inside Claude Desktop as an MCP server, using the same checks.

      Safe by design

      • Read-only: it never changes, installs or runs anything in your project.
      • Runs only on this computer (127.0.0.1); other websites cannot use it.
      • Secret values from .env are never shown, only the key names.
      • Fix commands are suggestions. Read each one before you run it.

      Shortcuts

      • / focus the folder box
      • Enter run the diagnosis
      • Esc close an opened layer
